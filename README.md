# tronkilu.studio

Portfolio site of Ergi Shkëlzeni — visual designer and illustrator based in Grenoble, France.

Static HTML, CSS and vanilla JavaScript. No build step, no frameworks, no trackers, no cookies. Served over HTTPS on GitHub Pages.

## Structure

```
index.html          Homepage
privacy/index.html  Privacy policy
legal/index.html    Legal notice
assets/fonts/       Geist (variable)
assets/video/       Hero video
CNAME               Custom domain
```

All copy lives in an `I18N` object near the bottom of each HTML file, with English, French and Albanian side by side.
